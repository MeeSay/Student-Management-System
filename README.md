# Student-Management-System
Chương trình quản lý danh sách sinh viên
# Các chức năng: 
- Nhập vào một danh sách sinh viên (nhập tay)
- In ra danh sách sinh viên
- Xóa thông tin sinh viên (mỗi lần 1 người)
- Chỉnh sửa thông tin sinh viên
- Lưu danh sách sinh viên vào file output.txt
- Đọc danh sách sinh viên từ file input.txt (sau đó có thể thực hiện các thao tác trên)
